## Description

Become a hungry cow and race the clock in a chaotic farm-wide grass eating contest.

You start with 60 seconds. Every patch of grass you eat adds score and time. The more you eat, the bigger your multiplier gets — but the field can run dry if you waste your route.

Can you keep the timer alive forever?
